# tinnulion.github.io

Personal one-pager of Igor Riabtsov — ML / AI / LLM Software Engineer.

## How it works

No frameworks, no build step — one HTML page, one stylesheet, one
script. The page fetches two YAML files and renders itself:

`travel_log.yaml` — the file one edits to update travel history. Edit, commit, reload.

## Run locally

```
python server/apptest.py [port]   # default 8000
```

## Vibe coding

This redesign was vibe-coded in a single session with **GLM-5.3**
(Z.ai) running in [OpenCode](https://opencode.ai). Cost around $1.00.
